# Spellforge

An offline browser roguelite about building spells from connected blocks.

Open `index.html` on a computer. On a phone, open `Spellforge-Mobile.html`; it contains the scripts and images in one file and does not need an assets folder.

## Build and check

```sh
node smoke-test.cjs
node realm-smoke-test.cjs
node build-standalone.cjs
node standalone-smoke-test.cjs
```

The soundtrack files can be placed in `assets/audio/` when ready. Sound effects are generated by the game.
